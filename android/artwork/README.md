# Launcher artwork

`launcher-source.png` is the original project icon generated with the built-in imagegen tool on 21 October 2026. `asset-tools/build-launcher-icons.mjs` creates deterministic Android density variants, padded adaptive foregrounds and the 512px listing image. The same existing game models are not depicted or modified by this illustration.

Prompt: A square, opaque, full-bleed Android launcher icon for Coastline Rush. A fictional lime sports coupe viewed from the front three-quarter angle, dark navy coastal road backdrop, restrained cyan headlights and speed streaks, polished 3D arcade racing style. No text, real brand logos, watermark, border or baked rounded mask. Strong small-size readability and safe margins for Android icon cropping.

Artwork files are included in the source repository; no generation credentials or signing keys are included.

`launcher-adaptive-source.png` is the built-in imagegen edit used for circular/adaptive launchers. Edit prompt: keep the same car and coastal scene, shrink the complete car to the central 52% width, and extend the continuous background to every edge without an inset frame or padding. Density generation only resizes the selected source artwork.
