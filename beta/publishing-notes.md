Use actual game captures for screenshots. Include the existing in-game asset credits in the APK; do not upload source code, signing keys or private repository archives.

The APK retains the existing development signing certificate for compatibility with prior tester installs. Keep that private key backed up securely. A future store signing plan may need a separate migration decision.

Before broad promotion, verify installation, graphics, tilt/buttons, simultaneous pedal input, audio, pause/resume and saved progress on several physical phones. Automated and desktop-browser checks do not establish native-device compatibility.

Android developer registration requirements can apply outside Google Play too. Google's limited-distribution option supports up to 20 devices; broader public distribution is a separate option. Check the requirements for the intended audience: https://developer.android.com/developer-verification

itch.io account login and any account/creator terms must be completed by the account owner where required. Uploading a free game does not remove licensing or platform obligations.
